A tiny Python program that writes one original one-line roast of the gadget I use every day — my robot vacuum, which has mapped every inch of my flat yet still hunts down the one charging cable on the floor and slurps it like spaghetti — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
